## Проблем с Model тестовете

Model тестовете имат проблем с относителните пътища в моделите. Моделите използват `../app/core/Model.php`, което не работи правилно когато се зареждат от тестовете.

### Решение (ако искаш да поправиш Model тестовете):

1. **Инсталирай Composer** (препоръчително):
   - Изтегли от: https://getcomposer.org/download/
   - Изпълни: `composer install`
   - След това използвай: `vendor/bin/phpunit`

2. **Или промени пътищата в моделите** (не се препоръчва):
   - Промени всички `require_once "../app/core/Model.php"` на абсолютни пътища
